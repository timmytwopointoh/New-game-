# Pek's Plunder: The Ghost Shift — v0.8
Offline Android restaurant game inspired by Peck's Old Port Cove, independently created (not an endorsed restaurant product).
Expanded kitchen and dining space, labeled two fryers/flat-top/grill/oven, three sinks and a commercial dishwasher, accessible doorways and collisions.
Ten fictional crew members plus four coin-unlockable fictional placeholders for consenting future restaurant staff.
New Game, Continue, Credits, persistent progress wallet, 12-minute escalating shift and independent ghost pranks.
All regular job steps have minigames with five variants each; seafood-residue dish washing and failed-food-drop tray retries.
Run node --check pecks-cove-capers/web/game.js and node pecks-cove-capers/test_logic.cjs.
