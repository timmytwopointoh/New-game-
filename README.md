# ECHOFORM

An original offline Android game prototype centered on replayable time echoes and persistent environmental memory.

## Build
Run `gradle :app:assembleDebug` with Android SDK 35 and Java 17. GitHub Actions builds an APK and launches an Android emulator smoke test.

## Status
This is a first playable 2D mechanics prototype, not yet photorealistic 3D. Preserve the existing Project-hail repository; all work belongs here.

## Development loop
Plan -> implement in isolated branches -> build -> emulator screenshot/logs -> review -> improve. Worker teams are a planned orchestration layer, not yet active autonomous agents.
