# Realm AI Live v0.25 — flight recovery and grounded walking

Update the existing Live installation normally. Package `com.veilforge.realmagent.live`, versionCode 200006 (`0.25-grounded-walks`), same permanent `77694D4F0068469CB6F7FD951F84946A4BBB833AE2702DC2F87B9E0C2ADABF22` certificate. Nintendo Switch authentication, its private saved-session folder, Microsoft link/Copy controls and all merged features are retained. No login reset or new signing key.

The prior client initialized its player but never sent Bedrock's loading-screen completion acknowledgement. It also sent stop-flying once and treated sending as success. This could leave temporary loading protections or active flight while the ground-only movement guard refused work. The fixes are:

- Send `serverbound_loading_screen` EndLoadingScreen (type 2) once actual nearby terrain is received. Dimension changes acknowledge the matching loading-screen ID and dimension transition; interrupted work stays stopped.
- Request only `flying=false` using `request_ability`, plus normal stop-flying action/input. Retry at one-second intervals, at most five times per flight episode, until this player's server abilities confirm flight is off. Pre-spawn/loading states do not consume the retry budget. A mode-button retry can restart a bounded attempt.
- A mode label alone no longer completes a pending change while unsafe abilities remain. An explicit same-mode reapply is permission-gated, deduplicated and sent through `/gamemode survival @s` or `/gamemode creative @s`; denial never invents abilities or triggers automatic reapply loops.
- Gravity continues while idle, stopped, waiting for flight confirmation or after server corrections. Actual received collision shapes determine ground contact. Unknown terrain and a server `on_ground` flag alone cannot manufacture a floor. Creative damage immunity/instant building are normal mode abilities and do not block grounded walking; active flight/noclip still do.
- Track server movement/jump locks without disabling gravity. Ignore vehicle and older-tick corrections; preserve current authoritative player feedback. Show flight recovery, loading, local collision contact, server ground reports and terrain state in movement status, with accurate waiting/landing explanations on the main status line.
