VEILFORGE Realm AI v0.17 test APK

This test build adds the saved-command Queue to the home screen, automatically selects newly prepared commands, lets a saved command be reused, and gives the home screen a round green Activate control and a blank red Commands control.

It also enables the app's server-verified movement, mining, and block-placement paths while the bot is in grounded Creative mode. Survival keeps the real-tool and inventory rules. In both modes, terrain, abilities, protections, and server feedback are checked; Stop remains immediate. The app does not teleport the bot.

The build uses the existing permanent signing certificate. APK and source overlay checksums and signature verification are included with the release. Actions outside the supported command catalog (including combat and actual crafting) remain unavailable; previews are not executable.
