OWNER'S INTENDED EXPERIENCE
===========================
The OWNER issues plain commands from authorized Minecraft Bedrock Realm chat.
The BOT understands Minecraft rules internally: no owner-facing knowledge menu,
no Google AI API key, and no repeated manual Activate button for a task.
Bot makes a bounded plan, walks and jumps physically, sees only blocks visible
with line of sight, finds resources, uses/crafts tools and chests, and waits
for authoritative server results. It remembers useful locations per Realm.
Goal is an autonomous player, NOT a teleporting entity or a fake simulation.

CORE COMMANDS
=============
  !ai get wood               Start continuous forestry until an explicit owner
                             return-home request or emergency stop (unless the
                             bot must halt on health, death, missing terrain,
                             disconnection, or safety failure).
  !ai chop down trees        Alias of above forestry job.
  !ai stop chopping trees    End harvesting and START a return-home logistics
                             job; distinct from emergency Stop.
  !ai return home            Also invoke homeward forestry logistics.
  !ai stop                   EMERGENCY cancellation of all work NOW; do NOT
                             silently treat this as 'bring wood home'.
  !ai roam / !ai explore     Travel toward a ~30-block direction by safe
                             observed steps and scan around; remember trees.
  !ai go get wood            Use nearby and remembered tree sightings.
  !ai find and mine <block>  Locate and mine visible known material, using
                             server-confirmed breaking and pickup checks.
Only authorized owner's in-Game chat should launch jobs.

FORESTRY MILESTONES — EXACT REQUESTED WORKFLOW
==============================================
Tree 1:
  - Chop ALL reachable logs belonging to the same tree; don't count 'tree
    finished' merely from breaking the first log.
  - Convert confirmed collected logs to correct planks; craft needed sticks,
    crafting table and SIX wooden axes once enough materials are available.
    Put axes in hotbar slots 1,2,3,4,5,6; use each until actual durability
    exhaustion, then move to an available axe. Check inventory and durability
    rather than forcing a new batch at any predetermined tree number.
  - For six axes, nominal requirements include 18 planks and 12 sticks;
    converting six planks to 12 sticks requires 3 stick craft batches in
    vanilla Minecraft. A table is 4 planks and a chest 8 planks. Acquire
    enough wood before attempting all crafts; NEVER invent supplies. The
    helper in code calculates 36 planks total with chest/table/six axes.
Tree 2:
  - Harvest entire tree. Craft/place the FIRST chest at/near the cleared
    tree site only after collision/placement/reach checks; step aside when
    needed. This FIRST CHEST is the permanent HOME base; never mine it.
  - If trunk logs remain above reach, navigate and safely climb/jump onto
    chest (only if collision and server placement confirm this is possible),
    look up and mine remaining wood. No teleport or unsafe pillar behavior.
Trees 3 and 4:
  - Continue felling, gathering drops, depositing wood and spare lumber
    supplies into the tree-2 home chest; verify transfer was accepted.
Tree 5:
  - Place the next chest after finishing the fifth tree.
Trees 6 and 7:
  - Deposit gathered wood in the tree-5 chest.
Repeat checkpoints at trees 8,11,14,17,... and deposit the following two
  trees into the latest chest. Do not create double chests accidentally.
When tools are exhausted:
  - Check the real tool durability and axe inventory; if replacements are
    needed and crafting is possible, craft more axes and refill slots 1–6.
    Do NOT blindly renew at tree 5 or tree 15. If unable to craft, report
    why, use safe bare-hand breaking when allowed, or safely pause.
  - Minecraft blocks vary in breakability and drops; unsuitable tools/hand
    can break many blocks but do not necessarily yield drops. Unbreakable
    blocks such as bedrock cannot be collected in normal survival.
  - If inventory fills, never throw away valuable wood; deposit, re-route,
    or pause safely. Track supplies separately from random filler drops.

RETURN HOME / SPECIAL STOP COMMAND — OWNER'S LATEST CHANGE
==========================================================
  !ai stop chopping trees   (and !ai return home)
must NOT merely terminate the job. It should:
  1) Abort any unfinished mining and STOP searching for new trees.
  2) Remember the complete harvesting route and server-confirmed chest
     locations. The tree-2 chest is the HOME ANCHOR: NEVER PICK IT UP.
  3) Visit later storage chests, preferably reverse order of harvesting.
  4) Open each chest using real Bedrock container transactions; read the
     SERVER-REPORTED inventory and withdraw wood, planks, and designated
     lumber supplies. Preserve tools and necessary supplies.
  5) When the player's inventory is full, navigate back to tree-2 home,
     deposit confirmed cargo into a home chest, and return to source. Make
     as many trips as necessary. If home storage fills, place recovered
     empty chests beside it (with a one-block gap to avoid double chests)
     and continue filling the home storage line.
  6) After server confirms a remote chest is EMPTY, break it carefully,
     verify the actual item was collected, bring it to home and place it
     in a line next to home. Do not break any chest still containing items.
  7) Finish ONLY when the stored wood is consolidated and all recovered
     chests are safely installed, or report exactly what remains blocked.
  8) If no tree-2 chest was ever actually placed, report the missing home
     base and avoid invented chest/container actions. Don't destroy the
     owner's pre-existing structures. Keep emergency !ai stop working NOW.
  9) For disconnect, death, stale terrain, or crashes, do not resume unsafe
     world edits automatically. Persist checkpoints to allow user-directed
     recovery without duplicating mining or chest operations.
