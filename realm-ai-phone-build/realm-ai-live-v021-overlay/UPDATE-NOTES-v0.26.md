# Realm AI Live v0.26 — jumping, dirt climbing, respawn and bug reports

Install over the existing Realm AI Live app. Package `com.veilforge.realmagent.live`, versionCode 200007 (`0.26-climb-recovery`), permanent certificate `77694D4F0068469CB6F7FD951F84946A4BBB833AE2702DC2F87B9E0C2ADABF22`. Nintendo Switch authentication, saved sessions, Microsoft link/Copy controls, glossary/learning, mining/building, saved commands and signed updater are preserved. No uninstall or key replacement.

The owner confirmed that v0.25 joins without floating and the bot can be touched. This update adds:

- Ordinary walking and following plan one-block jumps and drops through observed terrain, with actual jump input and collision-based landing. Feet-level Y can differ from the starting level. Low ceilings and server jump locks prevent jumping; movement never uses teleport commands.
- When an ordinary route is unavailable, a short supported dirt staircase can reach a nearby ledge up to four blocks higher. It requires actual known dirt in the hotbar and received terrain. A preview never changes the real world cache. Each placed step waits for a server block update and, in Survival, confirmed inventory consumption before jumping onto it. Creative uses the held block without consuming it. Existing builds, hazards and unknown cells remain protected. Stop cancels unfinished placement and keeps gravity running; already placed dirt remains. This is bounded local climbing, not unlimited tower building or general bridge construction.
- Server-confirmed death interrupts the active job and queue. The bot requests normal Respawn, acknowledges the server's ready-to-spawn position, and waits for positive server health. Previous work stays stopped. It does not invent health, grant immunity, reset login or resume jobs at spawn. Requests are bounded and Hardcore is reported as unavailable. A Respawn command allows an explicit retry while dead.
- Settings → Bug reports → Export ZIP saves an app-only diagnostic bundle using Android's save picker, even without a running bot or local API. Updates also links to Bug reports. Reports contain recent sampled movement/mode/terrain/death state, in-game coordinates, grouped symptoms, packet counts, safe source-frame locations for runtime errors and Android/updater event codes. History is bounded and private. Missing or malformed files still allow export.
- Reports exclude credentials, Microsoft codes/tokens, account names, chat, raw packet contents, arbitrary phone files and private signing material. Nothing is uploaded automatically. Attach the ZIP in the development chat for investigation; fixes arrive through the signed APK updater. This provides diagnostic export, not a live phone connection or remote code editor. Android still requests permission before installing an update.

They cover ordinary jumps/drops, Survival and Creative staircases, server/inventory confirmation, protected or unknown terrain, low ceilings, Stop, death/respawn ordering and limits, Hardcore, private bounded logs, malformed reports, offline export and the update-screen shortcut. Package/version, pinned signing certificate, 16 KB alignment and signed update notice are verified.
