# ECHOFORM — 3D game foundation

Godot 4.3 compatible prototype scene. Open game/project.godot in Godot, run the world scene. Arrow keys move, Space triggers a time echo. On Android, drag to move and tap right quarter to replay.

This is an engineering vertical-slice scaffold using placeholder meshes, not AAA graphics. Next: collision floor, art pipeline, real 3D character, environment streaming, reliable touch controls, echo interactions, performance profiling and Android export.

Keep changes on feature branches and require build/smoke checks before merging.
