# Sector Uprising II — AFTERLIGHT Visual Systems v0.3

Premium prototype, pending real GPU and Android QA. Adds physically suggestive metallic highlights, damp floor glints, more industrial architecture and trim, city skyline lights, emissive relay halos, dust/ash and warm floating embers, scanline HUD accents, and tiered graphics. The previous movement, combat, interactive grid relays, checkpoints, upgrades, mobile controls and save flow are retained.

Built offline using WebGL2, HTML/CSS/JS. `python scripts/sync-game-assets.py --check` must pass before Android build. Keep original Sector Uprising and installed VEILFORGE unchanged.

Use the separate PC engine project to run true WebGL screenshot tests and Android emulator build. These are not yet confirmed. Models from VEILFORGE/VQ require explicit local tool/API discovery and geometry validation; do not claim import without evidence.
